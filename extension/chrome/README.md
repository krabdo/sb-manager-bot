# Chrome 扩展

该扩展只在本地读取适用于 `https://sb.sb/` 的 Cookie、生成 `SBM1` 并写入剪贴板。它没有后台进程、内容脚本、存储权限或网络请求代码。

## 本地安装

1. 下载并解压 `sb-manager-bot-chrome.zip`，或者直接使用本目录。
2. 在 Chrome/Edge 打开 `chrome://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压后的目录。
4. 登录 sb.sb，打开自己的通知页，然后点击扩展图标。
5. 点击“复制 Bot 凭据”，立即粘贴到 Bot 私聊；绑定成功后点击“清空剪贴板”。

浏览器会提示扩展可读取 `sb.sb` 数据，这是读取 HttpOnly 登录 Cookie 所必需的。扩展不申请其他网站权限。
